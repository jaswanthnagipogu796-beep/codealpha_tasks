# CodeAlpha Stock Portfolio Tracker

## About the Project
The Stock Portfolio Tracker is a Python application that estimates the total value of stock holdings using predefined sample stock prices and user-provided quantities.

**Note:** This project uses fixed sample prices and does not fetch live stock market data.

## Features
- Stores sample stock prices in a Python dictionary.
- Calculates the value of stock holdings.
- Estimates the total portfolio value.
- Uses Python file handling and CSV support (where implemented).
- Displays portfolio calculations.

## Technologies Used
- Python
- Dictionaries
- Loops
- Arithmetic Operations
- CSV Module
- Date and Path Handling

## How to Run
1. Install Python 3 on your system.
2. Open the project folder in VS Code.
3. Open the terminal in the project folder.
4. Run:

```bash
python portfoliotracker.py
```

Replace `portfoliotracker.py` with your actual Python filename if it is different.

## How It Works
1. The program uses predefined sample prices for selected stocks.
2. The user enters stock symbols and quantities as supported by the program.
3. The program calculates the estimated value of the holdings.
4. It calculates and displays the total portfolio value.
