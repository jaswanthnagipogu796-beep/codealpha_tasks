# CodeAlpha Email Extractor

## About the Project
The Email Extractor is a Python-based project that extracts email addresses from a text file using regular expressions. It helps identify and collect email addresses from text automatically.

## Features
- Extracts email addresses from text files.
- Uses Python regular expressions (`re` module).
- Reads input files using `pathlib`.
- Displays extracted email addresses.

## Technologies Used
- Python
- Regular Expressions (`re`)
- File Handling

## How to Run
1. Install Python 3 on your system.
2. Open the project folder in VS Code.
3. Place the text file containing email addresses in the required location.
4. Run the Python file:

```bash
python emailextractor.py
```

Replace `emailextractor.py` with your actual Python filename if it is different.
