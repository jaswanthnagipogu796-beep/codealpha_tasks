# CodeAlpha Hangman Game

## About the Project
Hangman is a simple word-guessing game developed using Python. The player tries to guess a hidden word by entering letters within a limited number of attempts.

## Features
- Random word selection (if implemented in the code).
- Accepts letter guesses from the player.
- Tracks correct and incorrect guesses.
- Displays the current word progress.
- Provides win or lose messages.

## Technologies Used
- Python
- Conditional Statements
- Loops
- Strings
- Lists and Sets

## How to Run
1. Install Python 3 on your system.
2. Open the project folder in VS Code.
3. Open the terminal in the project folder.
4. Run:

```bash
python Hangman.py
```

Replace `Hangman.py` with your actual Python filename if it is different.

## How to Play
1. Run the program.
2. Enter one letter when prompted.
3. Continue guessing the hidden word.
4. Win by guessing the word before you run out of attempts.

## Learning Outcomes
- Understanding loops and conditional statements.
- Working with strings and collections.
- Developing basic game logic.
